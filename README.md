# Mary & Gabi Petshop

Site de um petshop fictício, desenvolvido como projeto de estudo no curso técnico da ETEC. Apresenta a loja, produtos, serviços e formas de contato.

**Demonstração online:** https://kayque2203.github.io/Projeto-Petshop/

> Mary & Gabi Petshop é uma marca fictícia. Preços, endereço e telefone da página são apenas demonstrativos.

## Seções do site

- Sobre nós
- Produtos, com imagem, nome e preço demonstrativo
- Serviços e galeria de fotos
- Contato, com formulário e dados fictícios

## Tecnologias

- HTML5
- CSS3 (layout com Flexbox e ajustes responsivos para celular)

## Estrutura de pastas

```
Projeto-Petshop/
├── index.html
├── css/
│   └── style.css
└── img/
    └── (logotipo, produtos e fotos da galeria)
```

## Como executar

Não é preciso instalar nada. Baixe o repositório e abra o `index.html` no navegador.

## Observações

- No formulário e nos botões "Comprar", este repositório não envia dados nem abre conversa: são apenas demonstrativos.
- Este projeto também aparece no portfólio da ATTICOWEB.
